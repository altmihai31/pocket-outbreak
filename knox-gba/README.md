# Pocket Outbreak

A Knox-style survival game for the GBA. The title screen and the ROM header (`POCKETOUTBRK`) carry the name since
playtest 1; the files, the save marker and the folder keep their old names (`knox.gba`, `knox.sav`), so emulator saves
keep working.

See `CLAUDE.md` and `docs/design-spec.md`. terrain detail and roads; towns and buildings; roofs), awaiting device testing; milestone 6 (zombie simulation) built (hordes as head counts, hourly migration, shared flow field, senses and outfits), awaiting device testing; ## Setup

- devkitPro with the **GBA Development** group (devkitARM, grit, gbafix, maxmod). `DEVKITPRO` / `DEVKITARM` must be set; the devkitPro installer does this.
- Butano checked out next to this folder: `../butano` (the Makefile uses `LIBBUTANO := ../butano/butano`). It's a git submodule: clone with `git clone --recursive`, or run `git submodule update --init` in an existing clone.
- Python 3 with Pillow (`pip install pillow`) for `tools/gen_assets.py`, which the build runs first to regenerate `graphics/` and `include/kx_world_gfx_ids.h`.

## Build

From PowerShell, `build.ps1` runs make through devkitPro's MSYS2 shell. Butano's makefiles break on the space in
"Project GBAzoid", so the script maps the parent folder to a temporary drive letter (`subst`) while it builds.

```powershell
.\build.ps1              # knox.gba
.\build.ps1 PROFILE=1    # knox_profile.gba: in game, L+Start shows bn::profiler results
.\build.ps1 DEBUG=1      # knox_debug.gba: tester build: "DEBUG BUILD" on the title, CPU readout on, assert stack traces
.\build.ps1 BENCH=1      # knox_bench.gba: scripted route through a 40-zombie horde (god mode), logs timings
.\build.ps1 BENCH=2      # knox_duel.gba: scripted fight against three zombies, logs hits, knockdowns, stomps
.\build.ps1 BENCH=3      # knox_loot.gba: scripted search of two cabinets and the gear menu, logs the inventory
.\build.ps1 BENCH=4      # knox_restart.gba: three deaths and retries (VRAM is freed between games)
.\build.ps1 BENCH=5      # knox_crawler.gba: a crawler comes in while the player swings at it
.\build.ps1 BENCH=6      # knox_survival.gba: fast time; bleed, bandage, eat, sleep, drink, die of infection
.\build.ps1 BENCH=7      # knox_travel.gba: sprint a loop through a generated world (seed 4B4E4F58), dump it
.\build.ps1 BENCH=8      # knox_save.gba: log the timeline, build base pieces, save a generated world and quit, load it (zombie hits on the barricade and a window), die, start the next survivor (a strong fire officer), read a book, start world events and listen to the radio; the round trip includes a jammed pistol with 7 rounds in hand, a flashlight on in the off hand, a spear and Molotovs, a door opened and one broken, a chopped tree's stump and canopy, a key's and a note's map marks and an opened gun safe; since milestone 13 it plays with sandbox settings that aren't the defaults (reset before each load, so the save's header must bring them back), and adds a snare, a hunted deer cell and the Smoker's clock
.\build.ps1 BENCH=9      # knox_vehicles.gba: on the test map, fix the car and drive it through zombies into a fence, ride the bicycle into a zombie, strip and siphon the wreck
.\build.ps1 BENCH=10     # knox_night.gba: a generated world at 22:30 with a 40-zombie horde: the flashlight, a campfire and a car's headlights outdoors, then the nearest building lit (grid power), dark 30 days on with the flashlight, a book read until its battery dies and the battery replaced, dawn indoors and back in by day, then the Map tab with a map and compass (marks set, cursor moved) and the mark arrow, then a siege of a battered car (the driver dragged out); it starts with self-checks of stitching, repair and the new traits (`KXFIVE`)
.\build.ps1 BENCH=11     # knox_guns.gba: a shooting range on the test map: the pistol (walking, standing, a reload), the shotgun, the hunting rifle and the assault rifle (A held) at zombies down the road, an active reload with a jam at Reloading 2 (a Police officer); then at night an alarm clock, a bottle and a Molotov thrown, the survivor stood in the fire, the spear, and a Molotov and a spear made in the Craft tab
.\build.ps1 BENCH=12     # knox_doors.gba: a generated world's houses: a door opened, a locked one rattling, opened with its key, forced with a crowbar, picked with a screwdriver and by the Burglar, unlocked from inside; a door shut in a zombie's face and broken by it; a safe's note read and the safe opened on its dial (a wrong code, then the right one); a stash's note read and the stash searched; a letter; a tree chopped; a wooden door hung and a log wall built (as a Carpenter), then broken by zombie hits; the Map tab with a key's mark
.\build.ps1 BENCH=13     # knox_wild.gba: the test map: a pond swum with a zombie left at its edge, drowning when exhausted, a heavy load kept out of the river and swimming to 8 tiles from land; a deer shot twice from a crouch and butchered, a flock walked into, rabbits killed with the pistol and the spear; a snare and a box trap over nights, a chest freezer through the power shutoff, a well; the sandbox settings' effects, a craving Smoker lighting up, a campfire lit with the lighter; a flock scattered by a shot, forced sleep at Tired 4, the Map tab's settings
.\build.ps1 BENCH=14     # knox_towns.gba: the generated world on the fixed seed: a loot census of every building (KXCENSUS; python tools/census_report.py <log> checks the targets), then a tour of each template and set piece (KXTOUR) while the music director picks the first tune (KXMUSIC)
```

Benches 1-6 play the hand-made test map (`include/kx_test_map.h`) so their routes and numbers stay comparable;
benches 7 and 8 play a generated world. Only the game and bench 8 touch SRAM; the other benches never save. Since milestone 14 bench 8 fills the item pool before its save (512 containers holding items, 1,816 stacks) so the round trip carries a full world. Bench
8 logs `KXSAVE` lines: the state before the save and after the load must match (position, clock, kills, carried
weight, food, the world's zombie total, containers and a checksum of every stored item stack; since milestone 12.5 also the chunks explored, the map marks, a flashlight's state and charge, a stitched wound and two of the new traits).

`python tools/save_roundtrip_test.py knox_save.gba` plays bench 8 headless in mGBA (`mgba-sdl`, a few seconds) and fails if any
`KXSAVE saved` line doesn't come back as the matching `KXSAVE loaded` line, or the settings, the sandbox or the next survivor are
wrong. CI runs it on every push and pull request, and a release is only published when it passes.

From a devkitPro shell on a path without spaces, plain `make -j` (with the same variables) works too.

Reading the bench numbers without a screen (`KXBENCH` and per-second `KXPOS` lines; add `STACKTRACE=1` to log a
stack trace if Butano asserts):

```powershell
& "C:\Program Files\mGBA\mgba-sdl.exe" -C logToFile=1 -C logFile=$env:TEMP\kx.log -l 255 knox_bench.gba
```

Bench 11 logs `KXGUN` lines: each phase's gun and zombies, every shot (rounds left, the cone, whether it was locked on, its angle, hits and kills), the aim every second (cone, lock, speed), reloads (at the end or fast, with the sweet spot), jams, and a tally per phase (shots fired and hit, kills, Aiming level, fast reloads, jams, Reloading level). It ends with a reload test: a jam, clicks on the jammed gun, clearing it, and a fast reload. Then `KXTHROW` lines (each throw and where it lands, the fire, zombies burned to death, the survivor's Burns, the spear's hits, a tally) and `KXCRAFT` lines (what the Craft tab used and made).

Bench 12 logs `KXLOCK` lines (the houses it found, keys rolled for a town, each phase's house, door and tools, what A did, how a pick or force ended, each door's state after) and `KXDOOR` lines (doors opened and closed, zombie hits with the door's health left), `KXNOTE` lines (the safes in the world, each note's text, what the safe and the stash held), `KXSAFE` lines (each code tried), `KXCHOP` lines (the tree, its canopy before and after, logs, the axe) and `KXWOOD` lines (the pieces built, their health, the hits that broke them).

Bench 13 logs `KXSWIM` lines (every 30 frames in the swimming phases: the tile, swimming or not, speed, endurance, Exhausted, Wet, Heavy load, health, the zombie's tile and a `FAIL` if any zombie ever stood in deep water) and `KXWILD` lines (each phase; what the animals noticed and at how many pixels; every shot's distance from the animal it passed; hits and health; the butchering's meat and hide; flocks taking off; the traps' nights and catches; the freezer's food by day through the shutoff; the well; the sandbox's effects; the Smoker's craving and cigarette; the lighter's uses; the forced sleep). Bench 7 also logs `KXWILD7` lines every 2 s: the cell and zone, and the deer, rabbits and birds about.

Bench 10 logs `KXNIGHT` lines: the darkness curve at dusk and dawn (with and without fog), the setup and the building it moves into, then every 30 frames the day and clock, the darkness, the flashlight (on, charge), the facing, whether a headlight beam shows and its angle, the campfires in view, whether the player is lit and could read, the renderer's state (night, roof hidden, room lit, roof cut-away and its level) and the display registers that can be read back (`DISPCNT`, `WININ`, `WINOUT`, `BLDCNT`, `BLDALPHA`). It also logs `KXMAP` lines (chunks explored, marks, the settlements' names), the zombies' sight every 300 frames (night, lit, sight and chase distances), each campfire calling the hordes, and the reading that starts and stops. Its phases last 10 s each so they can be looked at in mGBA.

Bench 9 logs `KXCAR` and `KXBIKE` lines (the car before and after the work, every 20 frames while driving, the bicycle, the wreck); bench 8 also logs the vehicles the seed put along its route and checks that a tracked car comes back from the save.

Bench runs also log `KXMISS` for every frame that overran, followed by where that frame went in per-mille (each timed system, then `other`: rendering, Butano, audio and anything untimed, such as a scripted teleport or save). To see the UI without a screen, add `DUMP=1` to a bench
build (`.\build.ps1 BENCH=6 DUMP=1` makes `knox_survival_dump.gba`): it logs the HUD layer every 20 frames, and
`python tools/render_hud_dump.py <log> <folder>` turns the dumps into PNGs (transparent pixels as a checkerboard; the palette is dumped too, so a screen that swaps colours, such as the Map tab, renders right).
`DUMP=1` without a bench (`knox_dump.gba`) dumps the title screen, then starts a world on its own. The travel bench
also logs `KXSYNC` whenever a chunk the screen needs had to be finished in one frame, `KXROOF` when the player enters or leaves a building, and dumps the macro map and
the chunk cache at the end: `python tools/render_world_dump.py <log> <folder>` draws `macro.png` and one `chunks_N.png` per view (where the route ended, then around the first six settlements).

## Controls

Button names are the Miyoo Mini's, as the game shows them: its L1 and R1 are the GBA's L and R (default
gpSP and mGBA mapping on OnionOS).

| Button | Action |
| --- | --- |
| D-pad | move (walk) |
| D-pad double-tap | jog until you let go of the D-pad (tap, release, press again within *Double-tap frames*) |
| A | context action: search the container in front of you, sleep in a bed, drink, tend a farm plot, generator, trap or fuel pump, or forage while crouched on wild ground (a prompt such as "[A] SEARCH" or "[A] WATER" shows when no zombie is close and you haven't swung for a second, so A keeps attacking through a fight), stomp a downed zombie, otherwise swing the item in hand (hold to charge). While grabbed: mash to break free |
| B | tap: shove (stagger every zombie in front); hold while moving: sprint |
| L1 | toggle crouch (on release) |
| Select | use the selected hotbar item: equip or put away a weapon, eat or drink, take medicine; the hammer opens build mode, the shovel opens it on the farm plot |
| L1 + Select | select the next hotbar slot |
| Start | Start menu (pauses): Gear, Health, Craft, Skills, Map and Menu tabs, L1/R1 to switch. Menu (also on the title: MENU with a save, Select on the new world screen without one; playtest 3, mockup 20) opens SETTINGS, GUIDE or WORLD with A (WORLD: the seed and sandbox settings, playtest 4; on the title only with a save), B goes back; its SAVE AND QUIT (not on the title) saves and quits to the title when A is held on it for a second (playtest 4; it was Select held on any tab), and shows "WORLD n% FULL" when the save's lists pass 80%. Settings: music and sound effect volumes (off, low, medium, full), screen shake, the CPU meter; kept in the save. Guide: how to play in 13 topics (Up/Down a topic, Left/Right its pages); the text is in `tools/assets/guide.py`, wrapped to the page there |

**Saving** (spec: Save system): one world in the 32 KB SRAM. The title screen offers CONTINUE (with the day and time of the save) or NEW WORLD, which warns that it replaces the saved world. Behind the title the saved world shows around where the survivor stood (a fixed village without a save), pixelated by the hardware mosaic, faded 60% to black and drifting slowly east; it fades in once the chunks on screen are built (`docs/title-backdrop-preview.png` is an offline mock-up of the look). The game saves when a new world or survivor starts, after sleeping, when you save and quit (MENU tab, hold A on SAVE AND QUIT), at death, and every in-game hour at half past while you are awake (that one is packed and written 256 bytes of world per frame, about an eighth of a frame, so it never stutters). Layout: two 2 KB character slots (header with magic, version, sequence, seed and clock, plus the character: position, clothes, inventory, body, clock, kills), the newer valid one winning, so a cut-off write never loses the character; then the world block (horde counts and recent noise, every container, the decals, the past survivors), LZ77-packed (playtest 6: a 23 KB world takes about 10 KB) into one of two copies in the 28 KB world area, written in turn, each with its own CRC-32, so a cut-off write leaves the other copy; a block that won't pack into half is stored as is across the area. If no copy checks out, the character continues on the seed's fresh world. `tools/power_cut_test.py` cuts the power every 61 bytes into a save and checks what loads. Containers are 8-byte records (up to 1024: position, loot table, opened bit); the 168 item pages of 12 slots (about 2000 stacks) go to the containers that still hold something, and when they run out an emptied container's page is reused, then the oldest zombie corpse's, then furniture's; dropped sacks are never taken. Up to 512 decals are remembered. "WORLD STORAGE NEARLY FULL" shows hourly once containers or pages are 90% used. Zombies on screen go back into the horde counts in the save.

**Character** (spec: Character; mockups 07 and 08): a new world, and every new survivor after a death, starts on the character creation screen: Left/Right pick one of 10 occupations (Unemployed, Mechanic, Carpenter, Nurse, Police officer, Fire officer, Chef, Farmer, Burglar, Park ranger, with the spec's starting skills; Unemployed gets +8 trait points, the Nurse's bandages stay clean twice as long), and A ticks traits, 11 good ones costing points and their 11 opposites giving them back (the stage 5 pairs are under Loose ends below) (Strong / Weak: Strength ±2; Athletic / Out of Shape: Fitness ±2; Fast / Slow Learner: XP ±30%; Light Eater / Big Appetite: hunger ∓25%; Fast / Slow Healer: wounds heal 50% faster / at half speed; Graceful / Clumsy: footsteps a tile quieter / louder; Unnoticed / Noticeable: zombies see you 25% less / more far; Brave / Cowardly: panic at half / 1.5x the rate). Start begins when the points are not negative (otherwise, for example after switching from Unemployed to an occupation without its 8 points, the info box turns red with how many points to give back and Start is greyed out); B goes back to the title. Traits for systems that don't exist yet (Smoker, Hard of Hearing, Outdoorsman...) come with those systems. Skills have 5 levels and level by doing: Blunt, Blade and Axe by hitting with that weapon class (each level: a 12% chance of a point more damage and a frame shorter recovery), First Aid by treating wounds (a treated wound heals 10% faster per level), Sneaking by crouch-walking near zombies that haven't noticed you (crouched, zombies see and hear you 8% less per level), Lightfoot by walking and jogging (footsteps a tile quieter at levels 2 and 4); the body stats Fitness (endurance lasts 10% longer per level above 2) and Strength (carry +1.5 kg and knockback +10% per level above 2) rise more slowly from exertion, hits and heavy loads. Carpentry trains in build mode, Foraging, Cooking and Farming with the food systems below; Mechanics trains by working on cars; Aiming trains by hitting with guns, Reloading by reloading them (see Guns) and Spear by hitting with the spear. A level gained shows a message. The **Skills tab** (Start menu, after Health) lists them with level pips (the next pip fills with XP); Up/Down pick one to see its level, XP, where its levels came from, its book and what it does. **Skill books** (one per skill, found in fitting places: medicine cabinets, garages, police lockers, desks, wardrobes, shop shelves, barns, tents) come in volumes 1-5 (early volumes more common, the volume shows in the item line); READ from the Gear tab takes an in-game hour per volume (the sleep fast-forward, awake), needs daylight or a flashlight carried and no zombies close, and once read, volume n multiplies the XP for going from level n-1 to n by 2, 3, 4, 5, 5. Magazines (canning, trapping, generator) take half an hour to read, with the same light rule, and teach what their name says for good (the Chef knows canning from the start). The character is saved (under 100 bytes). Tuning is in `include/kx_character.h`; `tools/mockup_character.py` draws mockups 07 and 08.

**Base building** (spec: Base building; mockup 06): put the hammer on the hotbar, select it and press Select to open build mode. The player stands still while the world runs on; L1/R1 pick a piece on the bar at the bottom, the D-pad moves the cursor (yellow brackets on a spot the piece can go, red otherwise) up to 3 tiles away, holding A builds while the time counts down top-left (hammering makes noise 12 every second, so clear the area first), and B leaves. The bar shows what the piece needs (carried/needed, green when there is enough), the tools and the noise, or why it can't go there; top-right shows the safehouse's pieces out of 64. Pieces: **barricade** (3 planks, 6 nails, hammer, 6 s) on a window, a smashed window or a doorway: solid, blocks sight, 100 health (250 if built at Carpentry 3; building on a damaged one mends it, and reinforces it once you reach Carpentry 3); **wooden crate** (4 planks, 8 nails, hammer, Carpentry 1): storage for 40 kg; **bed**: pick one up, then put it down elsewhere (you can't leave build mode holding it); **rain collector** (4 planks, 4 nails, a garbage bag, hammer, Carpentry 2): fills with rain once weather arrives (milestone 10); **campfire** (3 stones, 3 sticks, matches carried, outdoors): burns 6 hours, warms (insulation +6) and dries you within 3 tiles, gives light to read by within 4, shows a flickering flame; building it again on a fire adds 2 hours of fuel per plank or bundle of sticks (matches to relight a cold one), up to 12. Building trains Carpentry. Pieces belong to up to 3 safehouses of 64 pieces each, each one the building the first piece went in (plus 10 tiles around) or a patch of ground around it; a piece is a remembered wall graphic plus a 4-byte record, so a base costs no sprites. Garbage bags turn up in kitchens, shops and counters, sticks and stones in tents, crates and barns. **Zombies break in** (spec: attack barricades, smash closed windows, loud): chasing zombies follow the flow field through windows and barricades and hit what is in the way every 45 frames for 10; a window smashes after 3 hits (breaking glass, noise 12) and stays open for good, so zombies and the player climb through; a barricade bangs (noise 6) and breaks when its health runs out, uncovering what was under it. Coming back within 24 tiles of a safehouse after some time away rolls the horde passes: an attack on the weakest barricade per 40 zombie-hours in its area (15-40 damage each), with a message if they got through. Tuning is in `include/kx_base.h`.

**World timeline** (spec: World timeline and events; `mockups/world-timeline.png`): the clock shows the date ("3 JUL · 18:40", "NIGHT 3 JUL · 23:10"); day 1 is 1 July. The water goes off on a day between 10 and 20 and the power between 14 and 30 (the Normal shutoff sandbox setting; milestone 13), rolled from the seed (worked out from it, so nothing is stored), and you only find out when it happens. **Water**: each building has one kitchen sink and one bathroom sink (its first kitchen and bathroom cabinet, named KITCHEN SINK and BATHROOM SINK when searched); they show a "Tap water" entry in their grid while the water is on (A drinks, +25 water; it is never carried and leaves with the search screen); afterwards "THE TAP IS DRY". Shallow water, ponds and rivers ("[A] DRINK" in front of them) and rain collectors (the same prompt while they hold water) give +20 water but aren't boiled, so they can make you sick (35% from rivers and ponds, 10% from rain; BOIL WATER in the Craft tab makes a safe bottle). **Power**: food found in a fridge has aged a quarter as fast over the days the power was on. **Weather** (from the seed and the day, never stored): rain, fog or a storm on some days, for 2-9 hours (fog in the early morning), more often in autumn. Rain falls as sprite streaks (not indoors), soaks you outdoors (a raincoat keeps most of it off), halves every noise radius (spec) and fills rain collectors (3 drinks an hour, up to 40); a storm is rain with lightning flashes and thunder; fog hazes the world white (blending, cleared indoors where the roof fade needs it) and halves how far zombies see. **Seasons**: from day 60 the temperature falls (to 16 degrees colder from day 150) and the grass, leaves and forest floor turn autumn brown, then snow white in winter (palette blends, no new tiles). **Radio** (found in wardrobes, shop shelves and military crates): use it from the hotbar with a battery carried to hear the broadcast of the hour (survival tips, lore, the emergency channel) in a box with static; channels fall silent through the first week and a half, then there is only static; listening lifts morale. **Events**: the helicopter flies over your area once on a day between 6 and 9 (its shadow crosses the screen, the rotor gets louder and pans, and it makes a noise of 30 every half second along its path, so it drags hordes with it); each in-game hour while awake, maybe distant gunshots (noise 40), a house or car alarm wailing for 30 s (noise 60), or from day 3 a crash site (up to 3) 60-120 tiles away: a military crate with good loot, 12 more zombies in its area, and a smoke column for 3 days, drawn over the site or at the top edge of the screen towards it. Each event's noise moves the hordes. Debug page: "World event" (Left/Right pick, A starts) and "Skip 10 days". Tuning: `include/kx_timeline.h`, `include/kx_weather.h`, `include/kx_events.h`.

**Night** (milestone 12.5 stages 1-3; mockup 02): from 19:00 the world fades towards black one step at a time (the hardware fade has 16 steps), reaching full night (10 of 16) at 20:00; from 06:00 it lifts again, gone by 07:00. The HUD stays at full brightness; the world layers and the world's sprites (player, held item, zombies, vehicles, particles, rain, smoke) darken, campfire flames stay bright. At night the roof of the building you are in is not drawn at all (its cells are written empty) instead of fading out, and returns when you leave; at dawn indoors the day's cut-away carries on without it. Fog at night adds 2 steps of darkness instead of the white haze. A lightning flash lifts the darkness to a quarter for its few frames. Lights switch the fade off where they fall (window sprites, and a rectangle over a lit building), so what they light shows at full brightness:
- **Flashlight**: put it on the hotbar; Select takes it in the off hand and switches it on, then off and on (a click); see Off hand below. Its beam runs about 128 px (8 tiles) ahead from your chest along the way you face, sweeping round as you turn, with a small glow around you. A battery lasts 6 in-game hours; the bar under its hotbar slot shows the charge (yellow while on, grey while off, red when nearly flat). When it runs out it goes off ("FLASHLIGHT: BATTERY DEAD"); switching it on again puts in a Battery from your bag, or clicks and stays off without one. It switches itself off at 07:00 ("DAYLIGHT: FLASHLIGHT OFF"), drains only while you are awake, and goes dark while you drive (the headlights light the way). New flashlights (starting kits, the debug menu) have a full battery, found ones 20-100%.
- **Headlights**: a car with its lights on (R1 in the driver's seat, or left on) throws the same beam from its front along its heading; the car you drive comes first.
- **Campfires**: a round glow 4 tiles across on each burning campfire in view (up to 2).
- **Indoor lights**: the building you are in is lit while the grid has power, and after the shutoff while a running generator is within 10 tiles. The lights go out on the day the power does.

Night rules:
- **Light gives you away.** Zombies see you from 3 tiles at night, but from 6 (and keep you in sight to 10) while you are lit: a flashlight on, driving with the headlights on, within 4 tiles of a burning campfire, or in a lit building. Going dark is the stealthy choice.
- **Campfires draw hordes.** Each night hour every burning campfire heats its map cell as a 12-tile noise would, so hordes drift towards it when they migrate, also while you sleep beside it.
- **Reading needs a light that is on**: daylight, a flashlight switched on, a burning campfire within 4 tiles, a generator's lights, a lit building, or headlights (the car you drive, or lamps within 4 tiles). If the light goes while you read (the battery dies, the fire burns out), you stop ("TOO DARK TO READ ON") and the book has to be read again.
- Campfires that have burnt out are now marked out every hour. Their burn-out hour is kept mod 256, so before this an old fire looked lit again for a few hours about every 11 days.

One lot per cell holds the zone's landmark (villages a shop or petrol station, towns a police station, clinic, petrol station or shop, the military base a police-style HQ), the others homes and garages; each farm has a barn or farmhouse. Buildings have brick walls, windows you can see through, wood, tile or concrete floors and furniture to search (cabinets, fridges, wardrobes, tool and shop shelves, counters, lockers, medicine cabinets, crates, desks) and beds to sleep in. Variety without new tiles: ground textures, roofs and floors are mirrored at random per 8×8 piece (hardware flips; trees, bushes and rocks mirror whole, per column), and each building picks a roof colour (as drawn, brown, slate or moss green), a wall material (red brick, grey brick, white or yellow siding) and a floor (oak, light pine, dark walnut, red carpet; tile floors in four colours) from 9 extra palette banks, stored per tile as a style byte in the chunk cache. Templates come in 8 layouts (mirrored as well as turned), and furniture can swap for another piece of the same room (a kitchen cabinet for a counter or fridge, a wardrobe for a desk or crate...). The world palette now uses 11 of the 16 background banks and the HUD the other 5, so none are free. Roofs (spec: Roofs on BG1): every building has a red (homes, barns) or grey roof with a ridge, dark gable edges, a stone chimney on homes, a vent (red) or skylight (grey) and patches of moss or rust, on the canopy layer; stepping inside fades that roof out over 8 frames and leaving fades it back, through a window over the roofed part of the building with alpha blending, so tree canopies outside it stay solid. Outside doorways leave a gap in the roof, and a paved step leads to each front door (garages get a driveway), so entrances show from the street. In the wild, about one 12×12 block in three holds a find: an abandoned tent, a supply crate or, more rarely, a dead survivor. Generation values are in `include/kx_world_gen_tuning.h`. The world tileset must stay within 255 graphics (milestone 14: 1,020 hardware tiles over two charblocks, with the world maps cut to 32×32 cells; 128 before; asserted in `tools/assets/world.py`): background VRAM also holds the three world maps and the HUD canvas. To make room for the farm, generator, trap and can line tiles, where two different trees' canopies meet the tile now shows the lower tree's full canopy instead of a mixed one (6 graphics freed).

**Zombies** (spec: Zombies): every macro cell holds a 1-byte head count, seeded by zone (wilderness 0-4, farms 2-8, villages 15-30, towns 60-110, the military base 140-200; coast cells half, water none). Within 48 tiles of the player the counts materialise as zombies (one every 10 frames, up to 32 at once), out of sight and at least 12 tiles away, indoors when they can; zombies over 56 tiles away, or in chunks no longer generated, dissolve back into the count of their cell, and kills lower the counts for good. Every in-game hour the counts migrate: noises of 4+ tiles heat their cell, and cells within 6 cells of a hot spot (heat 24+ in the last 6 hours) send 30% of their zombies one cell towards it; elsewhere a few wander. The pass is spread over 64 frames (at once while sleeping). Chasing zombies that lose sight of the player follow a shared flow field (a breadth-first fill over the 64×64 tiles around the player, 128 tiles per frame, only while something chases and only as far as the farthest chaser) around walls and through doorways, for up to 10 tiles, then search the last known position for 20-60 s. Sight is 8 tiles by day and 3 at night (20:00-06:00); crouching in forest, mud or crops hides you beyond 2 tiles. Outfits by zone, as palette swaps: civilian, police (navy), soldier (olive), doctor (white coat, teal scrubs), farmer (red shirt, denim); towns have more police and doctors, the base mostly soldiers, farms farmers. A corpse's loot follows its outfit (police: flashlight, batteries; soldier: rations, compass, hunting knife, rarely a military bag; doctor: bandages, painkillers, antibiotics; farmer: apples, rope, matches). When the 32 sprites are all in use and more zombies wait within range, red arrows pulse at the screen edges towards them (faster for bigger crowds), with distant groans panned from the biggest one. Horde values are in `include/kx_horde_tuning.h`, outfits in `include/kx_zombie_outfits.h`; `mockups/zombie-outfits.png` shows the outfits and arrows.


**Content** (milestone 14, `docs/milestone-14-plan.md`; mockup `mockups/14-towns.png`). **Buildings**: 33 templates (`tools/assets/buildings.py`): homes (small and large house, cottage, bungalow, terraced pair, flat block, trailer, farmhouse, large farmhouse, holiday cabin, hunter's cabin), village landmarks (shop, petrol station, pub, post office, small school, and each village's church), town landmarks (police station, clinic, school, supermarket, motel, warehouse, fire station, pharmacy, hardware store, diner), the base (barracks, armory, mess hall) and farm outbuildings (barn, farm shed, stable); 3% of forest cells in the wild hold a cabin. Towns and the base have landmarks on the four lots by each crossroads and on a third of the rest. Lockers, shelves and counters loot by their building (a fire station's lockers, a pharmacy's shelves); 8 new loot tables. The asset build fails if a template's searchable furniture or beds can't be walked up to. **Set pieces**: the village church (graves behind it); in every town a crashed coach on a road into the centre (search its luggage, a body beside it) and a police barricade on a road out (a chicane of road blocks, sandbags, a police locker); the base's checkpoint (a barrier over two lanes, sandbags, a watchtower, a military crate). Zombies near the barricade and checkpoint mostly wear the uniform. **The wild**: campsites (a tent, a cold campfire and a crate) and hunter stands (in forest and woods, searchable). **Items**: 200 (70 new): 12 foods and 3 dishes (pasta dinner, rice bowl, fried eggs), sterile bandages (bandage and disinfect at once; boil two rags to make two), alcohol wipes, vitamins and cold pills (less sick), sleeping pills (tired enough to sleep), a first aid kit and a toolbox (opened into their contents), 8 melee weapons in the existing classes (the hatchet chops trees, the sledgehammer forces doors), a revolver and .38 rounds, pliers and wire (a lockpick: faster and surer than a screwdriver), scrap metal (hammered into a sheet that reinforces a barricade without Carpentry 3), a tarp (a rain collector's sheet), cloth (torn into rags) and a sewing kit (mends worn clothing), zip ties (mend a weapon), a bucket (waters plots), binoculars (reveal the map round you), a fishing rod (more finds by water), 20 clothes and bags (each its own colours on the survivor; hats now guard against bites), a car jack (tyres in half the time), a radiator and brake pads (REPAIR in the car screen puts condition back), tomato and onion seeds, and a kettle. The Craft tab scrolls (23 recipes). **Music** (`tools/assets/music.py` writes `dmg_audio/*.mod`; GBT Player on the old sound channels): the title loop, a calm-day tune and a night tune now and then with a minute or more of silence between, a chase loop while 3 or more zombies are after you (fading out 5 s after the last gives up), and a death tune. **Sound**: levels evened out (gunshots hit as hard as the loudest sounds, menu blips quieter), zombies' feet up close, glass underfoot on a smashed window, rain on the roof indoors, wind in the wild. **Balancing**: bench 14's loot census checks written targets (a house's kitchen about a day and a half of food, a loose gun in about 25 homes, the base 0.5-1.5 guns a building).

**The wild and loose ends** (milestone 13, `docs/milestone-13-plan.md`; mockup `mockups/13-wild.png`). **Swimming**: deep water can be entered on foot (not with Heavy load 2 or worse); you swim at half walking speed, soaked through, and it drains endurance like sprinting; at Exhausted 4 you lose 1 health a second ("YOU ARE DROWNING", bubbles) until you reach land, and a death there is DROWNED. Zombies, cars and bicycles never enter deep water: a chaser waits at the shore while you swim, and goes round once you're out. You can't swim to a tile with no land within 8 tiles ("TOO FAR FROM LAND"). **Animals** (`include/kx_animals.h`): deer graze in wild and farm cells (half of them, from the seed and the day; up to 2 at once) and notice you at 8 tiles, 3 crouched (less in forest and while they graze), then run; loud noise scares them too. Two rifle or shotgun hits drop one (3 pistol, 2 spear or axe, 4 other melee hits); guns lock on to an animal when no zombie is in front. "[A] BUTCHER" (hold 4 s, a knife or an axe in hand) turns the carcass into 4 raw meat and a deer hide (Foraging XP); "ROPE FROM HIDE" in the Craft tab makes 2 rope. A cell where you killed a deer has none for 7 days. Rabbits sit about by day (4 tiles, 1 crouched) and leave their meat where they fall; flocks of 3-5 birds take off with a flutter (a noise of 6) when you, a zombie or a loud noise come near. **Snares** (build mode, 1 rope and 1 plank, no magazine) catch rabbits overnight (30% a night, +5% per Foraging level); box traps catch a rabbit or a bird. **Chest freezers** (some kitchens, shops and petrol stations) keep food from ageing while there is power, from the grid or a generator within 10 tiles (worked out at midnight). **Wells** (every farm, half the villages, beside the crossroads): drink there ("[A] DRINK", 10% chance of sickness like rain water), fill watering cans, boil water. **TVs** in some living rooms: "[A] WATCH TV" while there is power. **Sandbox settings** on the new world screen (zombie speed, zombies, loot, shutoff, day length), kept in the save header and shown in the Map tab's margin. **Smoker** (bad trait, +2): after 8 hours without a cigarette ("YOU NEED A SMOKE") unhappiness climbs and panic is held up; a cigarette (3 s, a lighter or matches) lifts both. The **lighter** works like matches with 50 uses. **Loose ends**: Tired 2 and 3 make searching, building, reading and cooking take 25% and 50% longer, Tired 3 warns "YOU NEED SLEEP", Tired 4 dims the screen and you sleep 4 hours where you stand; Unhappy cuts XP (to 50% at Unhappy 4); aiming moves the camera 24 px along the aim; a take blocked by weight blinks the carried weight red; the pause menu shows `WORLD n%` when the save's lists pass 80% (a toast at 90%); loot is scaled by zone (military ×3 weapons and ammo, village ×0.8, big towns ×1.2, the wild and coast ×0.5).

## Layout

- `src/`, `include/`: game code, namespace `kx`. Hot loops live in `*.bn_iwram.cpp` (ARM code in IWRAM). Large global data goes in EWRAM (`BN_DATA_EWRAM_BSS`): IWRAM holds about 22 KB of code, so its globals and the stack share the remaining 10 KB, and a stack overflow there corrupts memory without an assert.
- `include/kx_movement_tuning.h`, `include/kx_camera_tuning.h`, `include/kx_combat_tuning.h`, `include/kx_loot.h`: the tuning tables the debug menu edits (movement, camera, combat actions, zombies, inventory, one table per weapon class).
- `include/kx_items.h`: the item table (ROM record per item type); `include/kx_loot.h`: loot tables by room type.
- `include/kx_test_map.h`: the hand-made 64×48 test map (character legend at the top), the benches' world.
- `tools/assets/buildings.py`: the building templates as text grids (legend at the top); the generator turns them four ways into `include/kx_buildings.h`.
- World: `kx_macro_map` (macro map), `kx_world` (chunk cache, decals, queries), `kx_world_gen.bn_iwram.cpp` (noise and chunk tiles), `kx_world.bn_iwram.cpp` (collision, line of sight), `kx_world_stream.bn_iwram.cpp` and `kx_world_renderer` (BG streaming from the cache).
- World timeline: `kx_timeline` (calendar, shutoffs), `kx_weather` (weather, seasons, rain and lightning on screen), `kx_events` (helicopter, gunshots, alarms, crash sites, radio broadcasts).
- Base building: `kx_base` (safehouses, pieces, barricade health, campfires, can lines, the visit roll), `kx_build_mode` (build mode, its cursor and the scrolling piece bar). Wall changes (pieces, plots, smashed windows, moved beds) are remembered with the decals and never forgotten.
- Food: `kx_recipes` (recipes, heat kinds, magazines), `kx_craft_screen` (the Craft tab), `kx_fixtures` (kitchen and bathroom sinks, stoves), `kx_farm` (plots and lazy crop growth), `kx_power` (generators, lazy fuel, fridge credit), `kx_traps` (box traps and snares and their nightly rolls). Foraging patches are FORAGE containers, removed when the search closes.
- The wild (milestone 13): `kx_animals` (deer, rabbits, birds, hunting, carcasses, hunted cells), `kx_sandbox` (the world's sandbox settings).
- Music (milestone 14): `tools/assets/music.py` composes the five loops into `dmg_audio/` (MOD files and their `.json`, converted by Butano for GBT Player); `kx_music` is the music director. `tools/census_report.py` reads bench 14's loot census.
- Vehicles: `kx_vehicles` (placement from the seed, the tracked list, parking as world obstacles, the bicycle, car physics, parts, keys, fuel, alarms), `kx_car_screen` (mockup 10). The bicycle's movement is in `kx_player`; `kx_world` holds the obstacle boxes that `box_blocked()` and the flow field check.
- Character: `kx_character` (skills, traits, occupations, XP and effects), `kx_creation` (the creation screen), `kx_skills_screen` (the Skills tab).
- Saving: `kx_save` (SRAM layout, CRC, slots, writing over frames), `kx_survivors` (permadeath and past survivors); each system writes its own part (`save`/`load` in `kx_containers`, `kx_hordes`, `kx_world`, `kx_player`).
- Zombie simulation: `kx_hordes` (head counts, materialising, dissolving, edge counts), `kx_hordes.bn_iwram.cpp` (the migration pass), `kx_flow_field.bn_iwram.cpp` (the shared flow field), `kx_horde_edges` (edge arrows and distant groans), `kx_zombies` (individual zombies).
- `tools/gen_assets.py` and `tools/assets/`: procedural placeholder art in the `docs/palette.md` colours and synthesized placeholder sounds; they also generate the index headers (`kx_world_gfx_ids.h`, `kx_hud_palette.h`, `kx_icon_pixels.h`, `kx_small_font.h`, `kx_item_icons.h`, `kx_sprite_frames.h`, `kx_weapon_frames.h`).
- UI (`kx_canvas`, `kx_hud`): BG0 is a 240×160 pixel canvas, one 4bpp tile per screen cell written straight to VRAM, so text (a 5 px Silkscreen-style font, `tools/assets/small_font.py`), 1 px frames, bars and icons sit at the mockups' pixel positions. Each cell has one palette bank: indices 1-7 are shared by all banks, 8-15 are bank colours (UI, body diagram, items, moodles, Health tab vitals). The HUD redraws an element only when what it shows changes. The pixel loops run from IWRAM (`kx_canvas.bn_iwram.cpp`). Only the debug menu still uses Butano's `common` 8×8 sprite font.
